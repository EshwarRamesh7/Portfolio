## Featured projects

### GDP Growth Prediction with Machine Learning & Explainable AI
World Bank indicators covering 257 countries and 2000–2023. Nineteen datasets were combined into a modelling dataset of 5,977 rows and 45 features. Linear Regression, Random Forest and XGBoost were compared; XGBoost achieved a test R² of 0.7361 and RMSE of 3.61 on the 2019–2023 holdout. SHAP was used to interpret predictions, alongside a three-page Power BI dashboard.

### Job Market Skills Intelligence — US vs India
A Python, MySQL and Power BI workflow comparing Data Analyst job postings, skill demand and salary patterns. The project uses a 134-skill vocabulary and a three-page dashboard. Its README documents unequal sample sizes and data-coverage limitations, so results are directional rather than a perfectly balanced market comparison.

### Global Retail Performance Dashboard
A three-page Power BI report for the Global Superstore dataset with 51,290 transaction rows across 147 countries and seven market groups. DAX measures and decomposition analysis support sales, profitability, discount and geographic exploration. Transaction rows are not unique order counts.

## Run the website locally

```bash
cd site
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

The Vercel project should use **Root Directory: `site`**, **Framework: Vite**, and the default build output **`dist`**.
